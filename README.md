# 🤖 AlphaBot

## Descrizione del progetto

**AlphaBot** è un progetto di robotica che ha come obiettivo la realizzazione e la programmazione di un robot in grado di interagire autonomamente con l'ambiente circostante attraverso sensori, attuatori e sistemi di controllo.

Il progetto permette di mettere in pratica le conoscenze acquisite nell'ambito della robotica, dell'elettronica e della programmazione, integrando componenti hardware e software per sviluppare un sistema intelligente e funzionale.
